
# 📊 HR Analytics Dashboard

## 📌 Project Overview
This project focuses on analyzing employee data using Power BI to uncover meaningful insights related to workforce trends, employee attrition, job satisfaction, salary distribution, and overall HR performance.

## 🎯 Objectives
- Analyze employee attrition patterns
- Understand workforce demographics
- Track department-wise employee distribution
- Monitor salary and performance trends
- Improve HR decision-making through data visualization

---

## 🛠️ Tools & Technologies Used
- Power BI

- Data Visualization
- DAX (Data Analysis Expressions)

## 📁 Dataset Information
This project uses two HR datasets:

1. **HR employee data.csv**
2. **HR Analytics Data.xlsx**

The datasets contain employee-related information such as:
- Employee ID
- Age
- Gender
- Department
- Education
- Job Role
- Salary
- Experience
- Attrition Status
- Performance Metrics
- Job Satisfaction
